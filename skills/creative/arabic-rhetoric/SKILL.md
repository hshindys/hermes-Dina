# Arabic Rhetoric (البلاغة) for Creative Writing

Activate when refining Arabic prose style, using rhetorical devices, or making Arabic writing more beautiful and persuasive.

## The Three Foundations of Balaghah

### 1. Maani (المعاني) — Meanings & Thought
Expressing meaning clearly, accurately, persuasively.
- Taqir (affirmation), Nafy (negation), Istifham (question)
- Istihlal (resolving contradictions), Ijtimal (combining opposites)

### 2. Bayan (البيان) — Expression & Clarity
- Haqiqah (literal/sincere)
- Majaz (figurative — the most powerful):
  - Istiara (metaphor)
  - Tashbih (simile)
  - Kinayah (indirect reference)
  - Mulazza (persistent metaphor)

### 3. Badi (البديع) — Aesthetic Beauty
Main devices: Simile, Metaphor, Metonymy, Irony, Litotes, Hyperbole, Rhetorical question, Parallelism, Antithesis, Alliteration, Repetition, Brevity (Ijaz), Word-play, Rhetorical chain.

## Using Balaghah in Arabic Fiction
- Jinn characters: formal/archaic Arabic heavy with Badi
- Human characters: colloquial Egyptian in dialogue, Fusha in narration
- Omniscient narrator: formal Fusha with elegant Badi
- First-person: personal voice, less rhetoric

## Daily Practice
- Write 5 sentences using a different Badi device daily
- Rewrite a scene using only Majaz language
- Read Al-Mutanabbi and Al-Jahiz aloud — mark rhetorical devices
- Imitate a masters style then find your own voice
